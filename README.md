# Scapy Network Toolkit & Packet Suite 🛡️

مشروع متكامل وموجّه للشبكات والأمان السيبراني مبني باستخدام مكتبة **Scapy** في بايثون. يجمع المشروع أهم المفاهيم البرمجية للتفاعل مع طبقات الشبكة المختلفة، فحص المنافذ، التقاط الترافيك، وتخصيص الحزم.

> 📚 **دليل التشغيل التفصيلي والشرح البرمجي**: تم إعداد ملف مخصص يشرح كل أداة بمخرجاتها وأوامرها: [TOOLS_GUIDE.md](TOOLS_GUIDE.md).

## 🎯 المفاهيم والوظائف المغطاة في المشروع

| الوظيفة | الوصف والطبقة | الاستخدام داخل المشروع |
| :--- | :--- | :--- |
| `IP()` | بناء وفحص ترويسة بروتوكول الإنترنت (Layer 3) | تحديد الـ Source و Destination IP، وإمكانية التزييف (IP Spoofing) |
| `TCP()` | بناء طبقة النقل المتصلة (Layer 4) | تحديد المنافذ وتفعيل الـ Flags (مثل SYN, ACK, FIN, RST) |
| `UDP()` | بناء طبقة النقل غير المتصلة (Layer 4) | إرسال حزم UDP خفيفة وحمولات (Payloads) |
| `ICMP()` | فحص رسائل التحكم والتشخيص (Layer 3) | تنفيذ Ping وفحص استجابة الأجهزة |
| `ARP()` | بروتوكول حل العناوين (Layer 2/3) | اكتشاف عناوين الـ MAC للأجهزة على الشبكة المحلية |
| `sr()` / `sr1()` | إرسال الحزم وانتظار الرد (Send & Receive) | فحص المنافذ بطريقة الـ SYN Scan، واختبار الاتصال بـ ICMP |
| `send()` | إرسال الحزم في Layer 3 دون انتظار رد | إرسال حزم مخصصة أو هجمات اختبارية |
| `sendp()` | إرسال الحزم في Layer 2 دون انتظار رد | إرسال Ethernet Frames مخصصة لكارت الشبكة مباشرة |
| `sniff()` | التقاط ترافيك الشبكة المار لحظيًا | مراقبة الحزم وتطبيق فلاتر BPF متقدمة |
| `.show()` | تشريح الحزمة وعرض كل حقولها وطبقاتها | عرض تفاصيل الحزم المصممة أو الملتقطة بدقة |
| `wrpcap()` | كتابة الحزم إلى ملف `.pcap` | حفظ جلسات الالتقاط لفتحها في Wireshark |
| `rdpcap()` | قراءة وتحليل ملفات `.pcap` | استخراج الإحصائيات وتشريح الحزم السابقة برمجياً |

## 📖 دليل الاستخدام التفصيلي (Step-by-Step Usage Guide)

عند تشغيل الأداة عبر:
```bash
sudo ./venv/bin/python main.py
```
يمكنك اختيار إحدى الأدوات التالية بكتابة رقمها والضغط على **Enter**:

### 1) 📡 مراقبة وتحليل الحزم المباشرة (Live Packet Sniffer)
* **ماذا تفعل؟**: تلتقط الترافيك الذي يمر عبر كارت الشبكة لحظياً وتسمح بحفظه.
* **خطوات الاستخدام**:
  1. اختر الرقم `1`.
  2. **فلتر BPF (Filter)**: اضغط Enter لالتقاط كل شيء، أو اكتب فلتر محدد مثل:
     - `tcp` (فقط ترافيك TCP)
     - `port 80 or port 443` (ترافيك الويب فقط)
     - `icmp` (حزم الـ Ping فقط)
     - `host 192.168.1.1` (ترافيك متصل بجهاز معين)
  3. **عدد الحزم (Count)**: أدخل عدد الحزم المطلوبة (مثلاً `20`) أو أدخل `0` للاستمرار في الالتقاط حتى تضغط `Ctrl + C`.
  4. **الفحص العميق (.show())**: اختر `y` إذا أردت عرض تشريح كل حزمة بالكامل، أو `N` للاكتفاء بملخص الحزمة في سطر واحد.
  5. **حفظ الحزم إلى PCAP**: اختر `y` واضغط Enter ليتم حفظ الملف تلقائياً داخل مجلد `captures/`، ويمكنك بعدها فتحه في برنامج Wireshark!

---

### 2) 📁 قارئ ومحلل ملفات PCAP السابق التقاطها (PCAP Analyzer)
* **ماذا تفعل؟**: تفتح ملفات `.pcap` السابقة المحفوظة من Scapy أو Wireshark لتحليلها واستخراج إحصائياتها.
* **خطوات الاستخدام**:
  1. اختر الرقم `2`.
  2. أدخل مسار الملف، على سبيل المثال الملف التجريبي المرفق:
     ```text
     captures/sample_test.pcap
     ```
  3. ستظهر لك إحصائيات فورية:
     - عدد الحزم الكلي ونسب البروتوكولات (TCP, UDP, ICMP...).
     - أكثر عناوين IP نشاطاً في الملف (Top Active IPs).
     - جدول بملخص الحزم الأولى.
  4. **تشريح حزمة معينة**: أدخل رقم الحزمة (مثلاً `0` أو `1`) لتطبيق دالة `.show()` وعرض جميع الهيدرز والحقول الخاصة بها، أو اكتب `q` للعودة.

---

### 3) 🔍 فاحص الأجهزة على الشبكة المحلية (ARP Network Scanner)
* **ماذا تفعل؟**: ترسل طلبات ARP Broadcast لاكتشاف كافة الحواسيب والهواتف المتصلة بالشبكة المحلية ومعرفة عناوين الـ MAC الخاصة بها.
* **خطوات الاستخدام**:
  1. اختر الرقم `3`.
  2. أدخل نطاق شبكتك (Subnet CIDR)، مثلاً:
     ```text
     192.168.1.0/24
     ```
  3. ستظهر لك قائمة منظمة تحتوي على:
     - عنوان IP لكل جهاز نشط.
     - عنوان الـ MAC الفيزيائي المقابل له.

---

### 4) 🎯 اختبار الاتصال وفحص المنافذ (Ping & TCP SYN Port Scanner)
* **ماذا تفعل؟**: تتأكد من أن الهدف متصل عبر ICMP Echo Request، ثم تفحص المنافذ المفتوحة بطريقة التخفي TCP SYN Scan (دون إكمال مصافحة 3-Way Handshake).
* **خطوات الاستخدام**:
  1. اختر الرقم `4`.
  2. أدخل IP الهدف، مثلاً `127.0.0.1` أو IP الخادم المراد فحصه.
  3. سيتم فحص استجابة الجهاز (Ping) وعرض ما إذا كان متصلاً (`UP`).
  4. سيتم سؤالك إذا كنت تريد فحص المنافذ المفتوحة (`Y`):
     - يمكنك الضغط على **Enter** لفحص المنافذ الشائعة تلقائياً (مثل 21, 22, 80, 443, 8080...).
     - أو يمكنك إدخال منافذ مخصصة تفصل بينها فاصلة (مثال: `22, 80, 3306`).
  5. ستحصل على جدول يوضح حالة كل منفذ: **Open** (مفتوح)، **Closed** (مغلق)، أو **Filtered** (محجوب بجدار ناري).

---

### 5) 🛠️ بناء وإرسال الحزم المخصصة (Packet Crafter & Sender)
* **ماذا تفعل؟**: تمكنك من صناعة حزمة بأي مواصفات وتحديد الـ Source IP (تزييف العنوان IP Spoofing) ومنافذ الـ TCP/UDP والـ Flags والبيانات (Payload)، ثم إرسالها إلى الشبكة.
* **خطوات الاستخدام**:
  1. اختر الرقم `5`.
  2. اختر نوع الحزمة المراد بناؤها:
     - `1`: حزمة **TCP** (تحديد الـ Flags مثل `S` لـ SYN، المنفذ، والبيانات).
     - `2`: حزمة **UDP** (تحديد المنفذ وحمولة البيانات).
     - `3`: حزمة **ICMP** (Echo Request).
     - `4`: إطار **Ethernet Frame** في Layer 2 (مع تحديد MAC الهدف والمصدر).
  3. أدخل الـ Destination IP.
  4. (اختياري) أدخل Source IP وهمي لتجربة الـ IP Spoofing، أو اضغط Enter لاستخدام عنوان جهازك الحقيقي.
  5. يتم عرض تشريح الحزمة بالكامل عبر `.show()` لمعاينتها قبل الإرسال.
  6. حدد عدد مرات إرسال الحزمة، وسيتم إرسالها فوراً عبر `send()` أو `sendp()`.

---

### 6) 📶 إدارة الواي فاي واسترجاع كلمات المرور (Wi-Fi Manager)
* **ماذا تفعل؟**: تفحص الشبكات الهوائية المتاحة، تعرض كلمات المرور المحفوظة على جهازك، وتتصل بأي شبكة لاسلكية.
* **خطوات الاستخدام**:
  1. اختر الرقم `6`.
  2. ستظهر قائمة فرعية بأربع عمليات:
     - `1` **فحص الشبكات المتاحة**: يعرض جدولاً بكافة شبكات الـ Wi-Fi القريبة وقوة الإشارة ونوع التشفير (WPA2/WPA3) والقناة.
     - `2` **عرض كلمات المرور المحفوظة**: يستخرج جميع كلمات السر لشبكات الواي فاي التي اتصلت بها سابقاً على هذا الجهاز.
     - `3` **الاتصال بشبكة واي فاي**: تدخل اسم الشبكة (SSID) وكلمة المرور ليتم الاتصال بها وأخذ IP عبر DHCP، مع إمكانية فحص منافذ الراوتر فور الاتصال مباشرة!
     - `4` **تدقيق أمان كلمة المرور (Password Audit)**: لفحص مناعة كلمة المرور ضد التخمين والقواميس وحساب الـ Entropy.

---

### 7) 🌐 الاكتشاف التلقائي لعنوان الراوتر وفحص منافذه (Router Gateway Scan)
* **ماذا تفعل؟**: تكتشف عنوان الـ Default Gateway للراوتر تلقائياً عبر كارت الشبكة النشط باستخدام Scapy، وتفحص المنافذ الحساسة المفتوحة به.
* **خطوات الاستخدام**:
  1. اختر الرقم `7`.
  2. اختر `1` للاكتشاف التلقائي:
     - سيقوم البرنامج بالتعرف على IP الراوتر (مثلاً `192.168.1.1`) والـ IP المحلي وكارت الشبكة.
     - سيتم فحص استجابة الراوتر للـ Ping.
     - سيتم فحص أهم منافذ الراوتر (لوحة التحكم: 80, 443, 8080؛ بروتوكولات الإدارة: SSH 22, Telnet 23؛ منافذ المشاركة: 139, 445; UPnP: 1900; و TR-069: 7547).
     - ستظهر لك تنبيهات أمنية في حال وجود منافذ غير مشفرة (مثل Telnet) أو لوحة تحكم ويب متاحة.

---

### 8) 🛡️ تشريح حزم الـ 802.11 Beacons وتحليل التشفير (Beacon Security)
* **ماذا تفعل؟**: تفحص حزم إدارة الواي فاي اللاسلكية وتحدد بدقة نوع تشفير الشبكة (Open, WEP, WPA2-Personal, WPA3-SAE, Enterprise).
* **خطوات الاستخدام**:
  1. اختر الرقم `8`.
  2. اختر `1` لتحليل ملف التقاط لاسلكي مسجل مسبقاً (`.pcap`)، أو `2` للالتقاط المباشر إذا كان كارت الواي فاي لديك يدعم وضع المراقبة (Monitor Mode).

## 💻 تشغيل الوحدات بشكل مستقل (Standalone Execution)

يمكنك أيضاً تشغيل أي وحدة برمجية مباشرة عبر سطر الأوامر دون فتح القائمة التفاعلية:

```bash
# 1. فحص شبكات الواي فاي القريبة والباسوردات المحفوظة
sudo ./venv/bin/python modules/wifi_manager.py

# 2. اكتشاف الراوتر التلقائي وفحص منافذه
sudo ./venv/bin/python modules/gateway_scanner.py

# 3. تشغيل مسح الشبكة المحلية (ARP Scanner)
sudo ./venv/bin/python modules/arp_scanner.py 192.168.1.0/24

# 4. تشغيل فحص المنافذ والـ Ping لجهاز معين
sudo ./venv/bin/python modules/port_scanner.py 127.0.0.1

# 5. تشغيل ملتقط الحزم المباشر مع فلتر مخصص
sudo ./venv/bin/python modules/sniffer.py "tcp and port 80"

# 6. تحليل ملف PCAP مسجل مسبقاً (لا يحتاج sudo)
./venv/bin/python modules/pcap_analyzer.py captures/sample_test.pcap

# 7. فحص أمان حزم الـ Beacons اللاسلكية
./venv/bin/python modules/wifi_sniffer.py

# 8. تجربة بناء وإرسال حزمة مخصصة
sudo ./venv/bin/python modules/packet_crafter.py
```

## 💡 أمثلة برمجية من الكود

### 1. إرسال واستقبال الرد عبر `sr1()` (TCP SYN Scan):
```python
from scapy.all import IP, TCP, sr1

# إرسال حزمة SYN إلى المنفذ 80
packet = IP(dst="192.168.1.1") / TCP(dport=80, flags="S")
reply = sr1(packet, timeout=1, verbose=False)

if reply and reply.haslayer(TCP) and reply[TCP].flags == "SA":
    print("Port is OPEN!")
```

### 2. اكتشاف الأجهزة عبر `ARP()` و `Ether()`:
```python
from scapy.all import Ether, ARP, srp

packet = Ether(dst="ff:ff:ff:ff:ff:ff") / ARP(pdst="192.168.1.0/24")
answered, _ = srp(packet, timeout=2, verbose=False)

for sent, received in answered:
    print(f"Host: {received.psrc} | MAC: {received.hwsrc}")
```

### 3. التقاط الترافيك وحفظه بـ `wrpcap()`:
```python
from scapy.all import sniff, wrpcap

packets = sniff(filter="tcp port 80", count=10)
wrpcap("captures/http_traffic.pcap", packets)
```

### 4. قراءة ملف وتحليله بـ `rdpcap()` و `.show()`:
```python
from scapy.all import rdpcap

packets = rdpcap("captures/http_traffic.pcap")
packets[0].show()  # تشريح الحزمة كاملة بالتفصيل
```
